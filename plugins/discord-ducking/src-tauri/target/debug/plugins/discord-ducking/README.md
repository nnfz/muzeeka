# Discord Ducking Plugin

Плагин для автоматического убавления громкости музыки когда кто-то говорит в Discord.

## Возможности

- ✅ Автоматическое определение активности Discord
- ✅ Плавное снижение и восстановление громкости
- ✅ Настраиваемый уровень громкости при дакинге (0-100%)
- ✅ Настраиваемая скорость перехода (50-2000 мс)
- ✅ Настраиваемая задержка перед восстановлением (0-5000 мс)
- ✅ Кнопка для тестирования дакинга

## Настройки

- **Включить автодакинг** — включает/выключает плагин
- **Громкость при разговоре** — уровень громкости музыки когда кто-то говорит (слайдер 0-100%)
- **Скорость перехода** — время затухания и восстановления громкости (слайдер 50-2000 мс)
- **Задержка восстановления** — пауза перед восстановлением громкости после окончания разговора (слайдер 0-5000 мс)
- **Проверить** — кнопка для тестирования дакинга (убавляет музыку на 3 секунды)

## Установка

1. Скопируйте папку `discord-ducking` в директорию плагинов
2. Перезапустите приложение или обновите список плагинов
3. Включите плагин в настройках

## Примечания

- Плагин работает только на Windows
- Требует запущенный процесс Discord.exe
- Текущая реализация использует простую проверку процесса (можно расширить через Windows Audio Session API для более точного детектирования)
